# T2C-Prov: Provenance-Anchored Text-to-CadQuery Generation Audit Chain

T2C-Prov is a system designed to anchor the provenance, contribution, and integrity of CAD artifacts generated by AI models onto a blockchain. It provides a robust framework for post-generation auditing, verification, and similarity detection for 3D designs.

## Core Features

- **Provenance Anchoring**: Automatically registers generated CAD scripts and geometry fingerprints on the blockchain.
- **Multi-Layer Hashing**: Ensures integrity through a 3-tier hashing strategy:
    - **Prompt Hash**: Normalizes and fingerprints the input prompt.
    - **Script Hash**: Uses Canonical AST normalization (Alpha-Equivalence) to ensure functional equivalence.
    - **Geometry Hash**: Extracts topological and physical features (7-tuple) for robust shape identification.
- **Advanced Audit Engine**: Implements a 4-level similarity metric to detect duplicates, derivatives, and original works.
- **Decentralized Storage**: Utilizes IPFS (Kubo) for immutable storage of original artifacts.
- **Blockchain Trust Anchor**: Smart contracts built with Solidity and Hardhat for secure, verifiable records.

## System Architecture

T2C-Prov integrates several key components into a seamless workflow:

1.  **Generation Engine**: CAD script generation using `ricemonster/qwen2.5-3B-SFT` with Apple MPS acceleration.
2.  **Cleaning & Export**: AST-based code purification and export to industry-standard STEP and STL formats.
3.  **Hashing & IPFS**: Calculation of multi-layer hashes and pinning to IPFS.
4.  **On-chain Registration**: Immutable anchoring of CID and hashes on the blockchain.
5.  **Audit Engine**: Comparative analysis using weighted fusion of Script (L1), B-rep (L2), and Mesh (L3) similarity.

## Setup & Installation

### Prerequisites
- Python 3.11
- Conda
- Node.js & npm (for Hardhat)
- IPFS (Kubo)

### 1. Python Environment
```bash
conda create -n t2c-prov python=3.11 -y
conda activate t2c-prov
pip install -e ".[dev]"
```

### 2. Blockchain Setup
```bash
cd chain
npm install
# Start a local hardhat node in a separate terminal
npx hardhat node
```

### 3. IPFS Setup
```bash
brew install ipfs # macOS
ipfs init
# Start the IPFS daemon
ipfs daemon
```

## Usage

### Generate and Register
Generate a CAD model from a prompt and anchor it to the blockchain:
```bash
python -m t2c_prov.cli.generate --prompt "a simple box with dimensions 10x10x10" --register
```

### Verify and Audit
Verify the existence of a model or perform a similarity audit:
```bash
# Verify by prompt
python -m t2c_prov.cli.verify --prompt "a simple box with dimensions 10x10x10"

# Audit a local STEP file against the registry
python -m t2c_prov.cli.audit --file path/to/model.step
```
